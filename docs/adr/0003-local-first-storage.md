# ADR-0003：本地优先存储，生产实现可替换

- 状态：Accepted
- 日期：2026-07-30

## 背景

项目需要持久化会话、运行轨迹、文件和知识向量，但用户明确希望尽可能少依赖中间件并支持简单启动。

## 决策

`local` profile 使用：

- H2 文件数据库保存结构化业务数据；
- 本地目录保存附件、知识源文件和 Skill；
- Spring AI `SimpleVectorStore` 保存演示向量数据；
- 进程内 Run 事件总线。

`enterprise` profile 后续提供：

- PostgreSQL；
- pgvector；
- S3/MinIO；
- 必要时才引入 Redis Stream 或消息队列。

## 约束

- `SimpleVectorStore` 不能被描述为生产级向量数据库；
- 向量文件写入必须加锁并原子替换；
- 文件路径使用服务端生成 ID，不能直接使用上传文件名；
- 业务代码依赖存储接口，不根据 profile 写条件分支；
- local profile 必须始终保持无需 Docker 可启动。

## 后果

正面：

- 首次运行门槛低；
- 演示数据重启后仍保留；
- 生产替换点明确。

负面：

- 本地向量存储不适合多实例和大数据量；
- 单机事件总线不能跨节点；
- 需要为本地和生产实现维护仓储契约测试。
